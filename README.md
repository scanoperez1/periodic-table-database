# Periodic Table Database

This project contains a PostgreSQL database with information about the first 10 chemical elements.

## Usage

Run the script with an element name, symbol, or atomic number.

Examples:

- ./element.sh 1
- ./element.sh He
- ./element.sh Neon

## Tests

The script has been tested with:

- Atomic number: 1
- Chemical symbol: He
- Element name: Neon
- Invalid element: 999
- No argument provided
